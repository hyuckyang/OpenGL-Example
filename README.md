
## 개발 환경 (Environment)
* **IDE:** Visual Studio 2022
* **Language:** C++
* **Graphics API:** OpenGL 3.3 (Core Profile)
* **Libraries:** GLFW, GLAD, GLM


## 2D 포물선 (Parabola)
<img width="392" height="394" alt="parabola" src="https://github.com/user-attachments/assets/b4523728-0215-479e-86a3-91258aa5ae9d" />

주요 기능 (Features)
* 실시간 2D 포물선 궤적 예측 및 물리 시뮬레이션 구현
* 간단한 수학 공식(Arctangent 등) 을 활용한 발사체 구현
* 간단한 사각형 장애물(AABB) 및 바닥 영역과의 충돌 검사

## 2D 시야각 (Field of View)
<img width="392" height="394" alt="b22" src="https://github.com/user-attachments/assets/914850ab-d9d0-4e3c-b145-776016a9a206" />

주요 기능 (Features)
* 벡터의 내적(Dot Product)을 실시간 2D 시야각(FOV) 객체 탐지 구현
* 간단한 수학공식을 활용한 선분과 원 경계의 교차점 계산 및 시야각 선분 렌더링
