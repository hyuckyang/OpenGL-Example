## 개발 환경 (Environment)
* **IDE:** Visual Studio 2022
* **Language:** C++
* **Graphics API:** OpenGL 3.3 (Core Profile)
* **Libraries:** GLFW, GLAD, GLM

주요 기능 (Features)
* 실시간 2D 포물선 궤적 예측 및 물리 시뮬레이션 구현
* 아크탄젠트(Arctangent)를 활용한 발사체의 실시간 회전 및 방향 변화
* 사각형 장애물(AABB) 및 바닥 영역과의 실시간 충돌 검사 처리
